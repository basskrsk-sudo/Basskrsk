# 2ГИС → Обзвон ХвостМаркета: предварительное согласование

Работает в **личном чате** Telegram-бота ХвостМаркет и MAX-бота.

Команда:

\`/2gis https://2gis.ru/krasnoyarsk/firm/70000001012345678\`

Также поддерживаются ссылки на геообъекты:

\`/2gis https://2gis.ru/krasnoyarsk/geo/70000001113304165\`

Можно переслать одну ссылку без команды. Альтернативное имя команды — \`/gis\`.

## Безопасная последовательность

1. Бот получает ссылку и проверяет, что организация ещё не добавлена.
2. Если подключён официальный 2GIS Places API (\`DGIS_API_KEY\` в Amvera),
   бот попробует получить подтверждённые название, адрес и телефон.
   Для \`/geo/<id>\` важно, что ссылка может вести на здание, а не на
   организацию: данные компании используются лишь после проверки типа \`branch\`.
3. Когда название не удалось получить, бот попросит сообщение
   \`Название | телефон | адрес\`. Достаточно названия.
   Указанные данные считаются данными сотрудника, не официальными данными 2ГИС.
4. Бот **показывает предложенную карточку**, её источник, ответственного
   и кнопки: **«✅ Добавить в обзвон»**, **«✏️ Изменить»**, **«❌ Отмена»**.
5. **Только нажатие «✅ Добавить в обзвон» создаёт запись в \`partner_leads\`
   и историю \`partner_lead_notes\`**. До этого сведения лежат в отдельном
   черновике \`dgis_bot_pending\` и не видны в CRM.
6. «Изменить» предлагает заново отправить всю строку данных и снова выдаёт
   карточку для подтверждения. «Отмена» или \`/cancel\` уничтожает черновик
   без изменений CRM. Срок черновика — **15 минут**. После решения старые
   кнопки недействительны, повторный клик не создаёт дубль.

Можно указать данные одной строкой:

\`/2gis https://2gis.ru/krasnoyarsk/geo/70000001113304165 | Зоосалон | +7 900 111-22-33 | Красноярск, ул. Мира, 1\`

И в этом случае **запись не создаётся без согласования**.

Права: активные менеджеры и администраторы с подтверждённой персональной
привязкой Telegram/MAX. Менеджеру контакт назначается автоматически,
администратор добавляет без ответственного. Менеджер не видит чужие
контакты. Проверка дублей работает по \`dgis_firm_id\`, \`dgis_url\` и
совпадению имени и контактных реквизитов при создании.

Ключи и токены никогда не сохраняются в репозитории.
