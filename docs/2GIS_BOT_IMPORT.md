# Импорт контактов 2ГИС в обзвон ХвостМаркета

Работает в **личном чате** Telegram-бота ХвостМаркет или бота MAX.

Команда:

\`/2gis https://2gis.ru/krasnoyarsk/firm/70000001012345678\`

Алиас: \`/gis\`. Можно также переслать саму ссылку 2ГИС без команды.
При желании заполните данные одной строкой:

\`/2gis https://2gis.ru/krasnoyarsk/firm/70000001012345678 | Название | +7 900 111-22-33 | Красноярск, ул. Мира, 1\`

Если имя недоступно через 2ГИС API, бот ответит просьбой отправить
\`Название | телефон | адрес\` следующим сообщением. Телефон и адрес
необязательны; их можно указать позже через раздел обзвона.
\`/cancel\` отменяет черновик. Он автоматически истекает через 15 минут.

Автоматическое заполнение названия, адреса, категории и доступных
контактных телефонов возможно **только при заданной переменной
окружения \`DGIS_API_KEY\`** (ключ Places API для ХвостМаркета).
При отсутствии ключа импорт по ссылке всё равно работает, но
данные нельзя угадывать — менеджер указывает название самостоятельно.

Из полной ссылки \`/firm/<id>\` берётся канонический ID организации.
Короткие ссылки \`go.2gis.ru\` / \`go.2gis.com\` разрешаются только
через проверенный allowlist HTTPS-хостов. Любые другие URL, маршруты,
поисковые страницы, неизвестные редиректы отвергаются.

Права: активные администраторы и менеджеры с привязанным Telegram/MAX.
Менеджеру контакт назначается автоматически, в его город; администратор
добавляет без ответственного. Для менеджеров не показываются сведения
о чужих лидах. Повторные карточки блокируются по \`dgis_firm_id\`
и \`dgis_url\`, а также по совпадающим названию и телефону/адресу.
Каждое создание фиксируется в \`partner_lead_notes\`, а карточка доступна
в Telegram Mini App → «Обзвон», кабинете менеджера и общей админке.

Пароли, ключи и токены не хранятся в коммитах.
Используйте 2ГИС API в пределах лицензии, а недоступные поля заполняйте вручную.
