# ХвостМаркет — Telegram Mini App, MVP v1

## Функциональность

- /miniapp.html: отдельный мобильный экран с фирменным стилем. Каталог и поиск, 4 категории, выбор салона, реальные остатки выбранной точки, фасовки, корзина, выбор грумера, промокод и действующий API ЮKassa.
- POST /api/miniapp/auth: серверная проверка Telegram initData через HMAC-SHA256 и отдельный секрет клиентского бота. Не приравниваем Telegram-имя к подтверждённому клиентскому кабинету.
- server/customer-miniapp-bot.js: новый, независимый бот. Устанавливает кнопку «🛍 Магазин», отвечает на /start, /shop, /help и запускает Mini App.
- При возврате ЮKassa на /miniapp.html?payment_return=... клиент проверяет оплаченный статус через сервер. Экран успеха не появляется до подтверждения paid.
- Обычный сайт, QR-карточки /p/... и действующие операционные Telegram-боты не заменяются.

## Как подключить клиентского бота

1. Откройте @BotFather в Telegram и отправьте /newbot.
2. Укажите имя «ХвостМаркет 🐾» и свободный username с окончанием bot.
3. В Amvera добавьте секретную переменную TG_SHOP_BOT_TOKEN с токеном **нового** бота. Никогда не публикуйте токен в чате, HTML, репозитории или в public/config.js.
4. Когда изменения этой ветки будут утверждены, объединены с main и развёрнуты на Amvera, перезапустите сервер с новой переменной. Приложение само настроит глобальную кнопку Telegram.
5. Нажмите Start у нового бота. Он отправит кнопку «🛍 Открыть ХвостМаркет».
6. Адрес Mini App: https://хвостмаркет.рф/miniapp.html. В обычном браузере он работает как демо просмотра с отключённой оплатой, после деплоя.

Важно: не используйте текущий TG_TOKEN операционных ботов. У нового бота не должно быть другого getUpdates-поллера или установленного webhook.


## Рабочие кабинеты в том же Mini App

В нижней панели /miniapp.html добавлена вкладка «Кабинеты». Из магазина или нового бота можно перейти к четырём рабочим ролям без отдельного приложения:

- Грумер: продажи за 30 дней, начисления, невыплаченная комиссия, текущий тариф, остатки своей точки и отправка заявки на пополнение.
- Менеджер: закреплённые точки, выручка за 30 дней, комиссия и бонусы к выплате, заказы и контроль низких остатков.
- Владелец: выручка своего салона, количество продаж, собственные начисления к выплате, статистика грумеров и последние покупки.
- Администратор: активные точки, последние 100 заказов с выделением оплаченных и операционные сигналы. Это не бухгалтерская сводка за месяц — для неё используйте полный кабинет.

Все эти данные приходят из старых защищённых API. Новых складов, заказов и пользователей в Mini App нет.

### Как войти

1. В Telegram выберите у клиентского бота кнопку «👤 Рабочие кабинеты» или команду /cabinet. Из магазина есть нижняя вкладка «Кабинеты».
2. Выберите нужную роль, введите **существующие** логин и пароль от кабинета на сайте. На текущем этапе первичный вход по паролю обязателен; Telegram-профиль сам по себе не открывает права.
3. Авторизационный токен работает 12 часов, как на сайте. Для каждой роли используется исходный ключ в localStorage, а API на сервере проверяют роль.
4. Кнопка «Открыть полный кабинет» переводит на страницу исходного кабинета на том же домене, сохраняя действующую сессию. Появится кнопка «← В мини-приложение» для возврата.
5. В Mini App доступен выход из роли. После выхода сохранённый токен этой роли удаляется.

Для администраторов действует серверная проверка прав супер-администратора: обычный админ не получает функций супера. Менеджер может читать только данные собственных точек; грумер — только свои заказы и остатки своей точки; владелец — свою точку. Нельзя открывать рабочие роли только по ID Telegram.

### Что ещё НЕ включено в мобильную сводку

Все подробные формы изменения карточек, управление реестрами, начисление выплат, настройка сотрудников и полный документооборот пока доступны через кнопку «Открыть полный кабинет». Это намеренно: опасные изменения требуют сохранения уже отлаженных серверных прав и сценариев. После приёмочного теста их можно постепенно переносить в нативные мобильные экраны.

## Приёмочные проверки до включения боевой оплаты

1. Выбрать каждый действующий салон и сравнить наличие/цены с админкой. Попробовать отсутствующую фасовку.
2. Добавить товар в корзину, изменить количество, выбрать другой салон и убедиться, что старый заказ не использует остатки новой точки.
3. На оформлении выбрать грумера или «Выбрал всё сам», ввести телефон, по возможности проверить промокод первой покупки.
4. Проверить, что Telegram initData проверяется на сервере, а недостоверная подпись не даёт оформить заказ через новый интерфейс.
5. Провести оплату сначала только в тестовом магазине ЮKassa. Проверить возврат, запись заказа, резерв и списание остатков, уведомления и атрибуцию грумера.
6. Повторить на iOS и Android Telegram: внешний редирект ЮKassa может вести себя по-разному внутри WebView.

## Ограничения первой версии

- Только самовывоз в салоне, без доставки.
- Telegram-профиль пока не связывается автоматически с личным кабинетом сайта: история заказов, косточки и персональные данные не открываются без отдельной проверки телефона.
- Для оплаты используется редирект на ЮKassa; возможность встроенного виджета можно рассмотреть после проверки клиентского пути.
- Фактический приёмочный тест на устройствах и боевое включение нового клиентского бота ещё требуются.

## Переменные окружения

- TG_SHOP_BOT_TOKEN: токен отдельного клиентского бота (нужен для авторизации и кнопки магазина).
- PUBLIC_URL: если задан, должен указывать на правильный публичный HTTPS-домен сайта для возврата из ЮKassa.
- TG_TOKEN / TG_CHAT_ID: текущие рабочие настройки, менять не нужно.

Справка: https://core.telegram.org/bots/webapps и https://core.telegram.org/bots/api#setchatmenubutton
