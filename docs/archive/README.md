# Архив материалов ХвостМаркет

Здесь хранятся исторические материалы, которые больше не требуются для работы сайта. Каталог не входит в публичную раздачу и Docker-образ.

- `taiga_notion_template.xlsx` — исходный исторический Excel-шаблон, перенесён без изменения содержимого.

Прежние версии маскотов и логотипов доступны в истории Git до коммита очистки статических файлов.
