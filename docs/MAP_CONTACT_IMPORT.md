# Универсальная команда /contact · CRM обзвона ХвостМаркета

Бот Telegram и MAX принимает ссылку на организацию в Яндекс Картах или 2ГИС.

Пример пересланного сообщения (можно вставить весь текст без команды):

Цацагрум
ул. Перенсона, 5А, Красноярск
https://yandex.ru/maps/org/tsatsagrum/16856539729?si=fq665ydvj26gdz0b8kuj1rpfeg

Другие варианты:

- \`/contact https://yandex.ru/maps/org/tsatsagrum/16856539729\`
- \`/contact https://2gis.ru/krasnoyarsk/firm/70000001012345678\`
- \`/contact https://2gis.ru/krasnoyarsk/geo/70000001113304165\`
- \`/contact <ссылка> | Название | +7 900 111-22-33 | Красноярск, ул. Мира, 1\`
- Прежние \`/2gis\` и \`/gis\` продолжают работать.

## Механика

1. Проверка роли: личный чат активного менеджера или администратора,
   связанный с Telegram/MAX. Сообщения покупателей не импортируют контакты.
2. В Яндекс Картах ID берётся **из URL**, название и адрес — только из
   текста, предоставленного сотрудником. Никакого парсинга Яндекс Карт
   и неразрешённого хранения сведений из API Яндекса.
3. Для 2ГИС сохранён официальный Places API при наличии \`DGIS_API_KEY\`.
   Ссылки на геообъекты /geo/ не считаются организацией без подтверждения
   типа \`branch\`.
4. При отсутствии названия бот попросит \`Название | телефон | адрес\`.
   Телефон необязателен.
5. Бот показывает предварительную карточку (название, адрес, телефон,
   ответственный, категория, источник). Кнопки: **✅ Добавить в обзвон**,
   **✏️ Изменить**, **❌ Отмена**.
6. Лишь подтверждение создаёт запись в общей CRM \`partner_leads\` и
   запись об источнике в \`partner_lead_notes\`. До этого данные хранятся
   в отдельном черновике с TTL 15 минут.
7. Повторные ссылки Яндекс Карт блокируются по \`yandex_org_id\` даже
   при изменении читаемого URL-имени (slug). 2ГИС проверяется по своему
   ID и URL. Перекрёстные дубли проверяются по имени и телефону/адресу.
8. В админке и Telegram-кабинете менеджера можно открыть ссылку карты
   непосредственно из сохранённой карточки.

\`/cancel\` уничтожает незавершённый черновик. Повторное или чужое
подтверждение не создаёт второй контакт.

**Условия лицензирования:** данные Яндекс Карт, которые не были
предоставлены самим сотрудником, не подтягиваются или не хранятся в CRM
без отдельного законного основания / разрешённого способа доступа.
