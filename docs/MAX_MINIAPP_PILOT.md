# MAX Mini App — тестовый пилот (ноябрь 2026)

## Цель и ограничения

Отдельное тестовое мини-приложение ХвостМаркета для существующего MAX-бота.
Пилот **только для чтения**: каталог, цены, фасовки, доступные остатки по
выбранной точке. Никаких платежей, броней, регистрации клиентов, назначения
ролей или доступа к складу через MAX Mini App на этом этапе нет.
Telegram Mini App на \`/miniapp.html\` не меняется.

## Путь и API

- Страница: \`https://хвостмаркет.рф/max-miniapp.html\`
- При необходимости латинское написание адреса для панели MAX:
  \`https://xn--80adktilqfjfx.xn--p1ai/max-miniapp.html\`
- Внешняя библиотека MAX Bridge: \`https://st.max.ru/js/max-web-app.js\`
- \`POST /api/max/miniapp/verify\` с \`{"init_data":"<MAX WebAppData>"}\`
- \`GET /api/points\`, \`GET /api/products\` — общедоступные
  справочники с данными существующего магазина
- Ответ верификации: \`verified\`, \`user\` (ID и имя), \`mode: pilot\`,
  \`checkout_enabled: false\`. Никаких bearer-токенов полномочий.

Подпись MAX проверяется на сервере через HMAC-SHA256 с ключом от
\`MAX_BOT_TOKEN\`, с проверкой свежести до 1 часа. Данные
\`window.WebApp.initDataUnsafe\` не используются для доступа.
В обычном браузере страница открывается для предпросмотра без MAX-авторизации.

## Действия в платформе MAX (один раз)

После публикации через GitHub/Amvera:

1. Открыть [MAX для бизнеса](https://business.max.ru/) с правами
   владельца существующего бота «ХвостМаркет».
2. Чат-боты → выбрать существующего бота → **Расширенные настройки**.
3. В поле URL мини-приложения указать
   \`https://xn--80adktilqfjfx.xn--p1ai/max-miniapp.html\`.
4. Выбрать кнопку **«Открыть»** и сохранить настройки.
5. В личном чате с ботом MAX отправить \`/app\`.
   Бот должен прислать кнопку **«🐾 Открыть тестовое приложение»**.
6. Открыть приложение: проверить, что MAX подтверждает имя, выбрать точку,
   просмотреть актуальные товары и нажать «Обновить остатки».

Бот добавляет команду \`/app\` в меню, а \`/shop\` является её алиасом.
Он использует штатный \`open_app\`, где \`web_app\` — текущий username
бота. Пока URL мини-приложения не сохранён в MAX для бизнеса, команда
может прислать кнопку, но MAX **не обязан** открывать приложение.

**Не путать** ссылку на страницу сайта с MAX deep link:
\`https://max.ru/<имя-бота>?startapp=pilot_catalog\` будет открывать
мини-приложение только после регистрации его URL для бота.

## Безопасность

Тестовые команды не требуют привязки номера, но и не дают полномочий
сотрудника. Для будущих кабинетов и покупок потребуется отдельная
серверная идентификация и подтверждение телефона. Платёжная логика
ХвостМаркета и действующий магазин Telegram не изменяются.
