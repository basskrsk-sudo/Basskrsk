# ХвостМаркет: действующие допущения для расчётов

Дата решения: 7 ноября 2026 года.

## Временная приостановка программы «Хвост помощи»

По решению собственника программа пока не отображается на публичном сайте.
В плановых и сценарных расчётах ХвостМаркета **не добавлять расход 10 ₽ с продажи/товара**.

Значение для новых финансовых моделей:
- «Хвост помощи» / благотворительные отчисления за покупку: **0 ₽**.
- Агентская схема: расход по программе **0 ₽**.
- Товар под реализацию / отсрочка платежа: расход по программе **0 ₽**.
- Юнит-экономика минимаркета, прогноз выручки и прибыли, расчёты по ассортименту:
  **не учитывать благотворительные отчисления**, пока не принято новое явное решение.

Это правило относится только к **новым и прогнозным расчётам**. Исторические реальные
перечисления, уже утверждённые обязательства и бухгалтерские документы менять
задним числом нельзя. При возобновлении программы требуется отдельное решение
об источнике финансирования, размере отчисления и дате применения.
