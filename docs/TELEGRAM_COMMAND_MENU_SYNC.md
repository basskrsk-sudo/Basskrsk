# Обновление меню команд Telegram (10 ноября 2026)

Команда \`/contact\` с Яндекс Картами и 2ГИС реализована и находится
в коде в \`server/2gis-lead-bot.js\`, но на iPhone пользователь сообщил,
что Telegram всё ещё показывает старый список с \`/2gis\`, без \`/contact\`.

Проблема: ранее \`configureBotProfile\` вызывал \`setMyCommands\`
только **в scope по умолчанию** и **один раз при старте**.
Telegram отдаёт приоритет более специфичным спискам для личных чатов
и русского языка. Ошибка API раньше только записывалась в журнал.

Решение:

1. Один список \`TELEGRAM_BOT_COMMANDS\` отправляется в три scope:
   - \`default\`;
   - \`all_private_chats\`;
   - \`all_private_chats\` + \`language_code=ru\`.
2. После каждой публикации список читается назад \`getMyCommands\`,
   сверяются имена и порядок команд, включая \`/contact\`.
3. Ошибка синхронизации записывается в журнал вместе с именем scope,
   ограниченно повторяется с задержкой 1, 5, 15 и 30 минут.
   Нет постоянного опроса Telegram или лишних запросов, когда всё успешно.
4. Активный администратор, у которого личный Telegram привязан к
   учётной записи \`admins\`, может отправить \`/syncmenu\`. Команда
   скрыта в обычном меню, повторно публикует три scope, проверяет их
   и присылает ответ об успешной синхронизации или ошибке.
   Неавторизованные пользователи не могут изменять меню.

## Проверка после деплоя Amvera

- В журнале запуска должно быть:
  \`Telegram: меню команд проверено (default, private, private_ru), /contact доступна\`.
- В личном чате бота открываем синюю кнопку «Меню» заново:
  **/contact — Контакт из Яндекс Карт или 2ГИС** должна идти сразу
  за **/2gis**.
- Если она не появилась, связанный администратор отправляет
  \`/syncmenu\` вручную.
- Если бот не знает даже эту новую команду, приложение Amvera
  по-прежнему работает на старом образе. Нужно проверить журнал сборки
  и перезапуск контейнера. GitHub CI сам по себе не подтверждает деплой.
- Клиентам можно пользоваться \`/contact\` вручную после того как новая
  версия сервера запущена — наличие команды в меню необязательно для
  обработки сообщений.

Не меняются настройки доступа к API, группы, роли, платежи и база CRM.
