# ХвостМаркет — резервные копии контекста

**Изолированная ветка:** `hvostmarket-context-backups` (не `main`). Эта ветка репозитория **публична**, поэтому здесь хранятся **только зашифрованные** снимки контекста и несекретные скрипты.

## Файлы

- `context-backups/snapshots/YYYY-MM-DD.json` — зашифрованная резервная копия (`X25519 + HKDF-SHA256 + AES-256-GCM`).
- `context-backups/crypto/public_key.json` — публичный ключ шифрования. С его помощью можно создавать новые снимки, но нельзя прочитать старые.
- `context-backups/crypto/encrypt_backup.py` — шифрование ZIP для выгрузки.
- `context-backups/crypto/decrypt_backup.py` — восстановление ZIP при наличии **приватного ключа владельца**, который **не хранится в GitHub**.

## Восстановление

1. Скачать нужный файл из `context-backups/snapshots/` и свой локальный `HvostMarket_PRIVATE_KEY.txt`.
2. Установить Python, затем `python -m pip install cryptography`.
3. Запустить:

   ```bash
   python decrypt_backup.py --key HvostMarket_PRIVATE_KEY.txt --input 2026-11-21.json --output hvostmarket_restored.zip
   ```

4. Распаковать полученный ZIP, прочитать `COVERAGE_*.md` и сверить контрольную сумму, которую сообщает скрипт.

## Важно об охвате

Автоматический недельный снимок содержит **только доступные на момент выполнения** решения, контекст и документы. Он **не равнозначен** официальному экспорту всех чатов ChatGPT и не содержит актуальную базу Amvera, если не предоставлена отдельная резервная копия. Чувствительные материалы не публикуются незашифрованными. Для полного восстановления нужны также приватные бэкапы `/data` и SQLite и история кода в `main`.

## Безопасность и деплой

Никаких изменений в `main` и конфигурации Amvera эта ветка не вносит. **Не сохраняйте приватный ключ, токены, пароли, незашифрованные SQL-дампы или клиентские данные в этой ветке.**
